# Elf Character Art Style & Design Language

## Asset Description
The Elf Ranger is a core character asset. She uses a bow and sword and wears green/brown leather ranger armor.

## Art Style Guidelines
- **Perspective**: 2D Isometric.
- **Resolution**: 128x128 per sprite frame.
- **Aesthetic**: Anime style, keeping the features cute and appealing while fitting a dark fantasy dungeon crawler theme (think Diablo/Torchlight meets anime).
- **Proportions**: Slightly exaggerated heads/eyes for readability, but generally human proportions suitable for an isometric camera.
- **Palette**: Vibrant greens and earthy browns for the armor against dark or gritty dungeon backdrops.
- **Hair**: Green, distinct silhouette that helps identify the character from top-down POVs.
